# NEDUET-3rd-Semester-Projects
Academic projects and practical work completed during the 3rd semester of Electrical Engineering at NEDUET.

## About This Repository:

This repository contains academic projects, practical work, laboratory assignments, circuit designs, simulations, and programming projects completed during the 3rd semester of the Bachelor of Engineering (BE) in Electrical Engineering at NED University of Engineering and Technology.

It showcases practical engineering knowledge, programming skills, circuit implementation, simulation techniques, and problem-solving abilities developed throughout the semester.

## Academic Information:

- **University:** NED University of Engineering and Technology
- **Department:** Electrical Engineering
- **Degree:** Bachelor of Engineering (BE)
- **Semester:** 3rd Semester
- **Academic Year:** 2026

## Projects Overview:

### 1. Electrical Design, Workshop and Practice (EDWP)

Practical electrical engineering projects involving electrical wiring, circuit design, hardware construction, and safety practices.

**Projects:**

- **PBL 1 – Extension Board**
  - Extension board design and construction
  - AutoCAD wiring diagrams
  - Physical implementation
  - Electrical safety and load calculations

- **PBL 2 – Safe Wiring Installation, Earthing and Fault Identification**
  - Electrical wiring installation
  - AutoCAD wiring diagrams
  - Earthing design
  - Physical implementation
  - Continuity testing and fault identification

### 2. Electronic Devices and Circuits (EDC)

Laboratory work and practical electronics involving circuit design, theoretical calculations, physical implementation, and simulation.

**Projects:**

- **OEL – Analog Audio Signal Level Indicator (VU Meter) Using LEDs**
  - Circuit design
  - Theoretical calculations
  - Physical circuit implementation
  - Multisim simulation
  - Simulation results and comparisons

### 3. Data Structures and Algorithms (DSA)

Programming assignments and projects focused on implementing data structures, algorithms, and problem-solving techniques using Python.

**Projects:**

- **DSA OEL**
  - Laboratory exercises
  - Python source code
  - Programming assignments

- **City Route Finder**
  - Graph data structure
  - Breadth-First Search (BFS)
  - Dijkstra's Algorithm
  - Custom Queue implementation
  - Route finding and distance calculation

- **Electrical Power Distribution System Using Tree Data Structure**
  - Tree data structure
  - Hierarchical representation of electrical components
  - Component insertion and searching
